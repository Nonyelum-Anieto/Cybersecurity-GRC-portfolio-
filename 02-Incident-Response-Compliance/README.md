# Cybersecurity Incident Response, Digital Forensics & Compliance — Banking Sector

## Project Overview

This academic cybersecurity project was completed as part of CTCH 660 at the University of Maryland Global Campus (UMGC).

The project examines incident response planning, digital evidence preservation, regulatory compliance, and cybersecurity governance through a banking-sector case study involving Tye Gate Bank.

## Project Objectives

- Develop a structured incident response approach for a financial institution.
- Identify appropriate digital evidence collection and preservation methods.
- Examine legal and regulatory considerations affecting forensic investigations.
- Evaluate forensic tools for different evidence sources.
- Propose incident response governance, communication, and performance measurement procedures.

## Frameworks and Tools Evaluated

- NIST incident response guidance
- Financial-sector regulatory and compliance considerations
- Autopsy / The Sleuth Kit
- Wireshark
- FTK Imager
- Splunk
- EnCase Forensic

The tools were evaluated for their suitability in a proposed investigation; this project does not claim hands-on use of every tool.

## Key Deliverables

- Incident response and evidence preservation strategy
- Digital forensic tool selection matrix
- Regulatory and compliance analysis
- Incident response governance and communication plan
- Incident response performance metrics and improvement roadmap

## Skills Demonstrated

Incident Response Planning | Digital Forensics Concepts | Evidence Preservation | Chain of Custody | Security Governance | Regulatory Compliance | Risk Management | Technical Documentation

## Project Scope

This is an academic case-study analysis and proposed incident response plan. It does not represent an actual bank investigation or production incident response engagement.
