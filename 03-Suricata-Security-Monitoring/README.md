# Network Intrusion Detection & Security Monitoring Using Suricata

## Project Overview

This academic cybersecurity lab project, completed at the University of Maryland Global Campus (UMGC), focused on configuring a Network Intrusion Detection System (NIDS) using Suricata 8.0.0 and Npcap.

The project involved network traffic capture, detection rule configuration, security alert analysis, and identifying potential network security threats in a controlled training environment.

## Tools Used

- Suricata 8.0.0
- Npcap
- YAML configuration
- Emerging Threats detection rules
- Network traffic and alert logs

## Project Activities

- Installed and configured Suricata and Npcap.
- Configured network monitoring settings and detection rule paths.
- Integrated an Emerging Threats ruleset.
- Captured and analyzed network traffic.
- Reviewed ICMP alerts and potential reconnaissance indicators.
- Examined alerts involving MySQL, PostgreSQL, and Microsoft SQL Server service ports.
- Investigated protocol-parsing errors involving DNP3, ENIP, and Modbus.

## Key Findings

The lab identified possible network reconnaissance activity, database-service probing indicators, and protocol-parsing issues.

These observations were not treated as confirmation of a successful cyberattack.

## Recommendations

- Establish baseline network traffic patterns.
- Prioritize investigation of potentially exposed database services.
- Tune detection rules to reduce unnecessary alerts.
- Review protocol and YAML configuration settings.
- Maintain and review security logs.
