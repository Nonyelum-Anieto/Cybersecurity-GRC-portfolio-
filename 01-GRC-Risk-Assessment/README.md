# GRC Risk Assessment & NIST Control Mapping

## Project Overview
This project focuses on identifying cybersecurity risks, evaluating their likelihood and impact, mapping security controls to the NIST framework, and developing remediation recommendations.

## Project Objectives
- Identify cybersecurity risks and vulnerabilities.
- Evaluate risk likelihood and impact.
- Map relevant NIST security controls.
- Develop a risk register and remediation recommendations.
- Document security assessment findings.

## Frameworks and Skills
- NIST Cybersecurity Framework (CSF)
- NIST SP 800-53
- Risk assessment and risk register development
- Security control mapping
- Risk mitigation and remediation planning
